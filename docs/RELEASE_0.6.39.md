## 수정

- 큰 최종 보고가 첨부로 전환돼도 전체 원문으로 완료·실패·진행 중을 판정한다. 로컬/원격 응답 대기, 데몬의 미응답 판단, 서버 완료 기록에 적용한다.
- 첨부 읽기 실패는 완료나 미응답으로 단정하지 않는다. 응답 대기는 오류를 표시하고 소비 확인을 유보하며 재전달로 재시도할 수 있다.
- 무인 실행 환경을 물려받아 실패하던 회귀 테스트 6건의 환경 의존성을 제거했다. 실제 무인 관리·복구 보호는 유지한다.
- CI에 무인 환경 회귀 검사를 추가했다.

## 검증과 적용

Windows GNU에서 공개 122건과 서버 57건(실제 통합 37건 포함) 및 양쪽 fmt/clippy 통과.
macOS·Linux 각 두 아키텍처와 Windows x64 설치 파일을 릴리스한다.
서버와 리시버를 함께 업데이트한다. 실제 사용자의 CLI 동일 세션 자동 주입 테스트는 배포 후 별도로 수행한다. 웹 대화 자동 주입은 범위에서 제외한다.

설치: https://brevduva.dev/install.sh 또는 https://brevduva.dev/install.ps1
