## 수정

- HTTP 전달 확인에 재시작에도 재사용하지 않는 증명을 적용했다. 서버와 리시버를 함께 업데이트해야 한다.
- 메시지에 따른 실행체 착수와 수신 소유권 전환을 예약으로 직렬화했다.
- 요청 대기에서 ACK와 진행 보고를 최종 답으로 오인하지 않는다. ACK만 남기고 실행체가 종료되면 미응답 실패를 알린다.
- 원격 MCP는 권한 회수를 기존 바인딩과 대기 중 수신에도 반영한다.
- 발행 성공은 저장 확인 뒤에만 반환한다. 불확실한 예약은 원본을 대조해 복구하며, 확인할 수 없으면 재시도 오류를 반환한다.
- 실패한 발행과 진행 보고가 업무 완료 기록을 남기지 않는다.

## 검증과 적용

Windows에서 공개 저장소 119건·서버 57건 전체 회귀 및 양쪽 fmt/clippy를 통과했다.
릴리스 파이프라인은 macOS·Linux 각 두 아키텍처와 Windows x64 바이너리를 생성한다.
OS별 실제 호스트 앱 자동 주입 실기는 별도이며, 웹 대화 자동 주입은 지원 범위에 포함하지 않는다.

저장 여부가 불확실한 예약은 중복 제거 창 만료까지 보류될 수 있다.
설치: https://brevduva.dev/install.sh 또는 https://brevduva.dev/install.ps1
