# brv 0.6.37

같은 신원의 대화형 수신자와 백그라운드 데몬 사이의 수신 경쟁을 수정합니다.

- 데몬은 최초 연결부터 기존 수신자를 존중하고 wake 직전 점유를 다시 확인합니다.
- 이전 연결의 버퍼·확인 토큰을 무효화하고, 재접속 후 전달 번호가 반복되어도 오래된 확인을 거부합니다.
- 점유 충돌과 연결 종료를 정상 타임아웃과 구분하며 종료 원인을 표시합니다.
- 서버 발급 수신 ID로 실제 전달 대상과 로컬 연결을 비교할 수 있습니다.

서버의 WS·HTTP·원격 MCP 공통 점유 수정과 함께 적용해야 합니다. 업데이트 후 실행 중인
CLI와 MCP를 재시작하고 원래 대화에서 자동 수신을 다시 활성화하세요. 웹 대화 자동 주입은 포함하지 않습니다.

Windows·macOS·Linux CI 및 서버 통합 회귀로 검증했습니다. 배포 바이너리는 SHA256SUMS로 검증할 수 있습니다.
